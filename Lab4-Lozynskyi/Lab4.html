Тест з основ веброзробки

Оберіть відповіді на запитання та натисніть «Завершити тестування». Для запитань із кількома відповідями за правильний вибір нараховується 1 бал, а за неправильний знімається 1 бал. Бал за кожне запитання не може бути меншим за нуль.

1. Яка мова задає структуру та вміст вебсторінки?
2. Яка технологія відповідає за стилізацію вебсторінки?
3. Які два елементи HTML зазвичай використовують для створення посилання та зображення?
4. Які три властивості належать до базової моделі CSS box model?
5. Який HTML-елемент створює нумерований список?
6. Які три варіанти є коректними способами підключення JavaScript до HTML? (можна обрати кілька)

Для вибору кількох варіантів утримуйте Ctrl (Windows) або Command (Mac).

7. Як називається мова розмітки, скорочення якої HTML?

Короткі теоретичні відомості

HTML — структура сторінки

HTML (HyperText Markup Language) — мова розмітки гіпертексту, що визначає структуру та зміст вебсторінки. Елемент <a> створює посилання, <img> додає зображення, а <ol> формує нумерований список.

CSS — оформлення

CSS (Cascading Style Sheets) описує вигляд HTML-елементів: кольори, шрифти, відступи та розташування. У моделі блока CSS вміст оточений внутрішнім відступом padding, рамкою border і зовнішнім відступом margin.

JavaScript — поведінка

JavaScript додає сторінці інтерактивність. Його можна розмістити безпосередньо в обробнику події, у блоці <script> в HTML або в окремому файлі, підключеному через атрибут src. Атрибут href у посиланні на CSS не підключає JavaScript.

Форми та елементи керування

Форми збирають введені користувачем дані. Перемикачі radio дають змогу вибрати одну відповідь у групі, прапорці checkbox — кілька відповідей. Елемент select створює список; атрибут multiple дозволяє вибрати в ньому кілька пунктів.
